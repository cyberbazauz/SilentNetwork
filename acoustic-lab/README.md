# SilentNetwork Acoustic Lab

Исследовательский проект для проверки физического канала SilentNetwork
(Architecture v1.0 §14). Цель — измеримые эксперименты с акустическим
сигналом, а не приложение и не сетевой протокол.

## Текущий статус

**BFSK-модем ещё не реализован.** В этом каркасе есть только инфраструктура:
конфигурация профилей, строгий WAV I/O, метрики BER/PER и модель канала AWGN.
Ни одна передача — файловая или через воздух — пока не выполнялась.

| Компонент | Статус | Задача |
|---|---|---|
| `snlab/config.py` — профили и валидация | реализовано, покрыто тестами | SN-008 |
| `snlab/wavio.py` — строгий PCM16 WAV | реализовано, покрыто тестами | SN-008 |
| `snlab/metrics.py` — BER, PER | реализовано, покрыто тестами | SN-008 |
| `snlab/channel.py` — AWGN | реализовано, покрыто тестами | SN-008 |
| `scanner.py` — устройства, форматы, шум | только CLI-интерфейс (код 2) | SN-010 |
| `transmitter.py` — сообщение → WAV | только CLI-интерфейс (код 2) | SN-011 |
| `receiver.py` — WAV → сообщение | только CLI-интерфейс (код 2) | SN-021 |
| `benchmark.py` — BER/PER по SNR | только CLI-интерфейс (код 2) | SN-013 |
| BFSK-модуляция и синхронизация | не реализовано | SN-020, SN-021 |

Заглушки CLI намеренно возвращают код `2` и печатают сообщение о запланированной
задаче. Они не создают файлов и не имитируют измерения.

## Уровни доказательности

| Уровень | Что проверяется | Что **не** доказывает |
|---|---|---|
| L0 — файловый канал | модулятор/демодулятор корректны на собственном WAV | ничего о реальном акустическом тракте |
| L1 — симуляция AWGN | устойчивость к шуму при заданном SNR | ничего о стенах, эхе, AGC, динамике |
| L2 — реальный воздух | передача динамик → микрофон | не гарантирует дальность и другие устройства |

Результаты уровней L0/L1 запрещено описывать как «передачу через воздух».

## Профили (гипотезы, не спецификация)

| Профиль | Fs, Гц | mark, Гц | space, Гц | симв/с | амплитуда | отсчётов/символ |
|---|---:|---:|---:|---:|---:|---:|
| `bfsk-16k` | 48 000 | 16 000 | 17 000 | 300 | 0.25 | 160 |
| `bfsk-18k` | 48 000 | 18 000 | 19 000 | 300 | 0.25 | 160 |

Частоты — стартовые значения для экспериментов. Рабочие частоты определяются
измерениями `scanner.py` на конкретном оборудовании, а не значением по умолчанию.

## Установка и тесты

```powershell
cd acoustic-lab
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m pytest tests -q
```

Тесты не обращаются к микрофону и динамику: они проверяют конфигурацию,
формат WAV, метрики и детерминизм модели канала.

## Запуск инструментов

```powershell
python scanner.py --list --out results/devices.json
python scanner.py --capture 10 --out results/noise.wav
python transmitter.py --message "SILENTNETWORK" --profile bfsk-18k --out results/tx.wav
python receiver.py --in results/tx.wav --out results/rx.txt
python benchmark.py --snr 0,5,10,15,20 --trials 100 --out results/ber.csv
```

Сейчас каждая команда завершится кодом `2` с сообщением о запланированной
задаче — это ожидаемое поведение каркаса, а не сбой.

## Результаты

`results/` — каталог для артефактов экспериментов. WAV, PNG, CSV и JSON
исключены из Git; итоговые отчёты `results/*.md` коммитятся. Каждый отчёт
обязан содержать профиль, seed, версии пакетов, устройство и честный раздел
«что не проверено».

## Ограничения

- Windows audio enhancements (AGC, шумоподавление) могут искажать сигнал;
  это нужно измерять, а не предполагать.
- Модель AWGN не учитывает реверберацию, многолучёвость, дрейф частоты и
  нелинейные искажения динамика.
- Поддержка 16–22 кГц не гарантирована ни одним устройством до измерений.

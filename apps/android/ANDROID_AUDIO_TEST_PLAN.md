---

## 1. Введение и назначение

Данный план описывает пошаговую методику физического тестирования акустического тракта смартфона с использованием раздела **Audio Lab** приложения SilentNetwork.

Цель испытаний — экспериментально подтвердить:
1. Аппаратную возможность излучателя (динамика) смартфона воспроизводить частоты диапазона 15–22 кГц (включая предварительный профиль BFSK M0: 18–19 кГц).
2. Аппаратную возможность микрофона смартфона захватывать сигналы в диапазоне 15–22 кГц с частотой дискретизации 48 кГц без искажений и программного подавления.
3. Наличие или отсутствие агрессивной фильтрации (AEC, AGC, Noise Suppression, low-pass фильтры) в режиме `AudioSource.UNPROCESSED`.
4. Уровень нелинейных гармоник, паразитных шумов и клиппинга.

---

## 2. Подготовка смартфона к тестированию (завтра)

Перед началом физического тестирования:

1. **Окружение:**
   - Выберите тихое помещение без посторонних громких звуков, эха и работающих вентиляторов/кондиционеров.
   - Расположите смартфон на мягкой поверхности (ткань, коврик для мыши) во избежание дребезжания корпуса от стола.
2. **Аудионастройки устройства:**
   - Установите громкость мультимедиа телефона на **30–40%** (ни в коем случае не на 100%, чтобы не перегрузить мембрану динамика).
   - Убедитесь, что в настройках звука телефона отключены эквалайзеры, Dolby Atmos, «улучшайзеры» звука и пространственное аудио.
3. **Разрешения:**
   - Предоставьте системное разрешение `android.permission.RECORD_AUDIO` при первом запросе приложения.

## 3. Инструкция по использованию Audio Lab в приложении

### 3.1. Как открыть Audio Lab
- Запустите приложение SilentNetwork.
- Нажмите на вкладку **Audio Lab** в нижней навигационной панели (между «Статус» и «Чат»)  
  *или*  
  Нажмите кнопку **«Открыть Audio Lab (Калибровка)»** на экране «Статус».

### 3.2. Как выбрать частоту и параметры
- В разделе **A. ПЕРЕДАТЧИК (Transmitter)**:
  - **Частота:** выберите из выпадающего списка:
    - `1000 Гц` — для первичной проверки динамика (слышимый контрольный тон);
    - `18000 Гц`, `18500 Гц`, `19000 Гц` — для проверки тестового профиля M0;
    - `15000 Гц`, `16000 Гц`, `17000 Гц`, `20000 Гц`, `21000 Гц`, `22000 Гц` — для сетки частот.
  - **Sample Rate:** оставьте `48000 Гц`.
  - **Длительность:** `2 сек` (или `3 сек`).
  - **Амплитуда:** начните с безопасного значения `0.15 (-16.5 dBFS)`.
  - В поле предпросмотра отобразятся выбранные параметры и цветовой индикатор профиля (`ГИПОТЕЗА M0`).

### 3.3. Как создать тестовый WAV (без звука)
- Нажмите кнопку **«Сгенерировать WAV»**.
- Файл PCM16 mono генерируется в фоновом кэше без воспроизведения звука.
- В строке статуса появится сообщение: `WAV успешно сгенерирован: ... (.wav)`.
- Кнопка **«Анализ тест-сигнала»** станет активной — можно проверить эталонный синтезированный спектр ещё до воспроизведения.

### 3.4. Как воспроизвести тестовый сигнал (физический тест динамика)
> [!WARNING]
> Воспроизведение звука разрешено только завтра в дневное время!
- Нажмите кнопку **«PLAY (Воспроизвести)»**.
- Появится диалоговое окно безопасности:  
  *«Сейчас через динамик телефона будет воспроизведён тестовый сигнал ... на низкой амплитуде. Продолжить?»*
- Нажмите **«Воспроизвести»**.
- Для экстренной остановки нажмите кнопку **«STOP»**.

### 3.5. Как записать сигнал микрофоном (физический тест микрофона)
- В разделе **B. ПРИЁМНИК (Receiver)**:
  - Выберите длительность записи (`3 сек`, `5 сек` или `10 сек`).
  - Нажмите кнопку **«НАЧАТЬ ЗАПИСЬ»**.
  - Приложение активирует `AudioRecord` (источник `UNPROCESSED` с fallback на `MIC`) строго на выбранное время.
  - В строке статуса отображается текущий прогресс: `Запись аудио... 2.1 / 5 сек`.
  - По окончании записи отобразится: `Запись завершена: получено N сэмплов (PCM16 mono)`.
  - Для досрочной остановки нажмите **«ОСТАНОВИТЬ ЗАПИСЬ»**.

### 3.6. Как проанализировать запись
- Нажмите кнопку **«Передать в анализатор»** в разделе приёмника  
  *или* нажмите **«Импортировать WAV из памяти»** в разделе анализатора.
- Анализатор мгновенно вычислит на борту устройства:
  - **RMS (dBFS)** и **Peak (dBFS)**;
  - **Клиппинг:** количество перегруженных отсчётов и статус-бейдж (`КЛИППИНГ: НЕТ` или `КЛИППИНГ ОБНАРУЖЕН`);
  - **DC offset:** постоянное смещение нуля;
  - **Доминирующую частоту:** пик спектра в Гц;
  - **Долю энергии 18–19 кГц:** процент мощности, попавший в целевой диапазон;
  - **Таблицу главных спектральных пиков**;
  - **Спектральный график (PSD):** наглядная визуализация частот от 0 до 24 кГц с подсветкой полосы 18–19 кГц.

### 3.7. Как экспортировать WAV и JSON
- Для WAV: нажмите **«Экспорт записи WAV»** (или «Экспорт тест-WAV»).
  - Откроется стандартный системный диалог выбора папки Android Storage Access Framework (SAF).
  - Сохраните файл в папку «Загрузки» (Downloads) или на карту памяти.
- Для JSON: нажмите **«Экспорт JSON-отчёта»** в разделе анализатора.
  - Сохраните файл отчёта `silentnetwork_calibration_report.json`.

## 4. Сценарии сквозного тестирования «Телефон ↔ Компьютер» (Завтра)

Для проведения тестов используется ПК с запущенными скриптами Python Acoustic Lab Agent 1 (`acoustic-lab/transmitter.py`, `acoustic-lab/receiver.py`, `acoustic-lab/calibrate.py`).

### Сценарий 1: ТЕЛЕФОН → КОМПЬЮТЕР (Проверка динамика телефона и микрофона ПК)
1. Разместите телефон на расстоянии **0.5 м** от микрофона компьютера.
2. На компьютере в терминале запустите приёмник Acoustic Lab:
   ```bash
   python acoustic-lab/calibrate.py --rx --duration 5 --output results/phone_to_pc_18500hz.wav
   ```
   *(или `python acoustic-lab/receiver.py --record --output results/phone_to_pc_18500hz.wav`)*
3. На телефоне в разделе «Передатчик»:
   - Частота: `18500 Гц`
   - Длительность: `3 сек`
   - Нажмите `PLAY`.
4. Компьютер запишет WAV-файл.
5. На компьютере запустите анализ спектра:
   ```bash
   python acoustic-lab/calibrate.py --analyze results/phone_to_pc_18500hz.wav
   ```
6. **Ожидаемый результат:**
   - Чёткий пик на 18 500 Гц (±20 Гц).
   - Уровень пика выше фонового шума минимум на 15–20 dB.
   - Отсутствие сильных паразитных гармоник в слышимом диапазоне (< 16 кГц).

---

### Сценарий 2: КОМПЬЮТЕР → ТЕЛЕФОН (Проверка динамика ПК и микрофона телефона)
1. Разместите телефон на расстоянии **0.5 м** от динамиков компьютера.
2. На компьютере сгенерируйте и подготовьте тестовый тон 18 500 Гц:
   ```bash
   python acoustic-lab/calibrate.py --tx --freq 18500 --duration 3 --output results/pc_tx_18500hz.wav
   ```
3. На телефоне в разделе «Приёмник»:
   - Длительность записи: `5 сек`.
   - Нажмите **«НАЧАТЬ ЗАПИСЬ»**.
4. Сразу же на компьютере запустите воспроизведение сгенерированного тона:
   ```bash
   python acoustic-lab/transmitter.py --file results/pc_tx_18500hz.wav
   ```
5. По завершении 5 секунд записи на телефоне:
   - Нажмите **«Передать в анализатор»**.
   - Нажмите **«Экспорт записи WAV»** и сохраните файл как `phone_rx_from_pc_18500hz.wav`.
   - Нажмите **«Экспорт JSON-отчёта»** и сохраните `phone_rx_report.json`.
6. Скопируйте файлы на компьютер через USB-кабель.
7. Проверьте WAV-файл через анализатор Acoustic Lab:
   ```bash
   python acoustic-lab/calibrate.py --analyze phone_rx_from_pc_18500hz.wav
   ```
8. **Ожидаемый результат:**
   - Микрофон смартфона успешно зарегистрировал 18 500 Гц.
   - Бортовой анализатор телефона и Python Acoustic Lab дают идентичные результаты по частоте пика и RMS.

---

### Сценарий 3: Сетка частот 15–22 кГц (Определение граничной частоты среза)
Повторите тест на частотах:
`15000`, `16000`, `17000`, `18000`, `18500`, `19000`, `20000`, `21000`, `22000 Гц`.

Фиксируйте падение амплитуды (Roll-off) на высоких частотах. Это позволит точно определить верхнюю физическую границу аудиотракта конкретной модели смартфона.
